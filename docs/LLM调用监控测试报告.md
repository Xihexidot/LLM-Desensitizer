### 2.2 统计准确性验证方式

- **自洽性**：`todayTotal == 插件 + API == Σ渠道 == Σ趋势各小时`
- **受控增量**：插入指定数据后断言精确增量（如 DeepSeek 插件 +2、chatgpt 别名归一至 OPENAI API +1）
- **千级准确性**：1200 条数据全部入统计，12 个平台完整覆盖

### 2.3 异常识别有效性验证

| 告警类型 | 触发条件 | 测试结论 |
| --- | --- | --- |
| `HIGH_FREQUENCY`（HIGH） | 单员工 ≥ 20 次/日 | 20 次精确触发，员工账号掩码 `u-***` 展示，不泄露完整账号 |
| `RISK_SPIKE`（HIGH） | 当日高风险 ≥ 10 次 | 触发且等级正确 |
| `BLOCK_SPIKE`（MEDIUM） | 当日阻断 ≥ 10 次 | 触发且等级正确 |
| `UNKNOWN_PROVIDER`（MEDIUM） | 未登记平台 ≥ 5 次 | 触发，详情保留原始标识供排查 |

### 2.4 权限校验验证

- 匿名请求 → `403`
- `X-Monitor-Role: USER` → `403`
- `AUDITOR` / `ADMIN` / `OPERATOR` → `200`；小写 `auditor` 归一后 `200`
- `OPTIONS` 预检不被拦截

### 2.5 回归验证

监控模块开发前项目测试集为 92 个用例，本轮全量回归 **129 个用例全部通过**，无回归（脱敏、检测、代理等历史功能不受影响）。

## 5. 已知限制与后续建议

- 自动刷新间隔固定 10 秒，如需实时性更高的场景可改为 WebSocket / SSE 推送
- 压力测试数据为模拟聚合数据；真实千级并发场景建议在网关侧做基准压测
- `dist-e2e` 为 E2E 专用构建产物，不进入生产部署；生产使用 `dist/`
